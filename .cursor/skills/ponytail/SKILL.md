# Ponytail (Tailwind)

Not installed. Current styling is `src/shared/styles/app.css`.

When Tailwind is added:

- Do not duplicate spacing already in `.page`, `.auth-form`, `.data-table`.
- Keep class lists short; extract a class in `app.css` if repeated.
