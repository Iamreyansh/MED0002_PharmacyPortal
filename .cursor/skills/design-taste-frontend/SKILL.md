# Design taste

Pharmacy console: dense, calm, high-contrast, rupee amounts. Prefer existing `src/shared/styles/app.css` tokens over new palettes.

- Information density over decoration. One primary action per region.
- Do not install GSAP, shadcn, or Tailwind unless the user asks. Skills exist for later UI work.
- Pair with `ponytail` if utilities are introduced later.
