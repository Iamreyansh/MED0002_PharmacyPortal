# UX and Accessibility Standards

- Target WCAG 2.2 AA for all portal and MFE screens.
- Every interactive control is keyboard reachable, visibly focused, named, and operable without pointer precision.
- Status, errors, locks, and charts never rely on colour alone; dynamic feedback uses appropriate live-region behavior.
- Data tables provide headers, responsive alternatives, pagination/filter labels, and an intentional empty state.
- Forms preserve safe input after validation failure, connect errors to controls, and prevent accidental duplicate submission.
- Loading uses stable layout; destructive and financial actions require clear intent and server confirmation.
- Responsive behavior supports narrow mobile and desktop layouts without hiding authorized capability.
- Dates, currency, and quantities use Indian locale presentation while API values retain Core formats.
